# 分组刷词：退出入口 + 组内完成态

## 摘要

「刷这组」目前是单向的：切进分组队列后，只有刷到队尾才可能出现「刷剩下的」（混用全局文案），没有任何可见的退出入口；如果全局都刷完了，连这个按钮都不出现，会卡死在这组里。

本次补齐两件事：

1. **随时退出**：分组模式下，刷词页顶部状态条出现「C 组」标记 + 「退出」按钮；点退出恢复到进入分组前的全局队列、第几张、撤回快照（就像分组刷词没发生过）。
2. **组内刷完**：刷完本组最后一张时不再套用全局的「这轮刷完了 / 今天全部刷完」文案，改为「C 组刷完了 · 共 6 个」+ 两个按钮「回到全部」「再刷一遍」。

## 现状分析

全部改动都在 [index.html](file:///d:/apt/英语单词/mobile/index.html)：

- 队列与作用域：L1204–L1208 `queue / pos / animating / deckScoped`；`savePos()` L1169–L1173 在 `deckScoped` 时直接返回（分组刷词不写 `mb.pos`，已实现）。
- 进入分组：L2036–L2046 `queueLibLetter(L, list)` 直接覆盖 `queue/pos/undoSnap`，**没有备份全局状态**，所以目前只能靠 `mb.pos` 重新推导。
- 状态条：L1540–L1552 `renderDeckShell()`，结构为 `<span>第 <b id="deckPos"> / <b id="deckTotal"> 张</span>` + `.deck-tools`（撤回 / 遮住答案 / 音效）。
- 空态：L1611–L1627 `renderCard()` 队尾分支，按 `ratedToday()/allDone` 输出「这轮刷完了」或「今天全部刷完」，并给一个 `data-restart`「刷剩下的」按钮。
- 点击委托：L2301–L2347 `#view-deck` 的 click；其中 L2320–L2321 处理 `[data-restart]`（会 `deckScoped = false` + `buildQueue(true)`）。
- 可复用：`restorePos(q)` L1175、撤回快照 `undoSnap` L1680、`.undo-btn` 样式 L210–L220、`.rate` 按钮样式（空态已用 `class="rate r2"`）、`esc()`、`toast()`。

### 4. 作用域进入 / 退出 / 重刷（替换 L2036–L2046 的 `queueLibLetter`，并在其后新增两个函数）

```js
/* 刷这组：临时替换刷词队列，不写全局进度存档 */
function queueLibLetter(L, list){
  if(!list || !list.length || animating) return;
  if(!deckScoped) deckBackup = {queue: queue, pos: pos, undoSnap: undoSnap};
  deckScoped = true;
  deckScopeLabel = L;
  queue = libSorted(list);
  pos = 0;
  undoSnap = null;
  hardCloseLib();
  renderDeckShell();
  switchTab('deck');
  toast('已切到 ' + L + ' 组 · ' + queue.length + ' 个词');
}

/* 退出分组：原样回到进入前那张 */
function exitDeckScope(){
  if(!deckScoped || animating) return;
  if(deckBackup){
    queue = deckBackup.queue;
    pos = deckBackup.pos;
    undoSnap = deckBackup.undoSnap;
  } else {
    /* 兜底：没有备份时按今天的存档重建 */
    queue = buildQueue(false);
    pos = restorePos(queue);
    undoSnap = null;
  }
  deckBackup = null;
  deckScoped = false;
  deckScopeLabel = '';
  renderDeckShell();
  toast('已回到全部单词');
}

/* 再刷一遍这组：位置归零，词序不变 */
function replayDeckScope(){
  if(!deckScoped || animating) return;
  pos = 0;
  undoSnap = null;
  renderDeckShell();
  toast('再刷一遍 ' + deckScopeLabel + ' 组');
}
```

要点：
- 已在分组中再从词库点另一组时，**不覆盖 `deckBackup`**，退出始终回到最初进入前的位置。
- `savePos()` 已有 `deckScoped` 早退，退出后无需补写存档（全局 `mb.pos` 未被改动）。

### 6. 点击委托（`#view-deck` L2301–L2347）

在 `undoBtn` 分支之后、`[data-rate]` 之前插入：

```js
if(e.target.closest('#scopeExitBtn') || e.target.closest('[data-scope-exit]')){
```

```js
if(restart){ e.preventDefault(); deckScoped = false; deckBackup = null; deckScopeLabel = ''; queue = buildQueue(true); pos = 0; savePos(); undoSnap = null; renderDeckShell(); return; }
```

## 假设与决定

- 退出分组**恢复进入前那张**（已确认），包括撤回快照；不是从头刷全局。
- 组内刷完**停留在完成页**，提供「回到全部」「再刷一遍」两个按钮（已确认），不自动跳转。
- 分组标签沿用字母本身（`C 组`），不做中文别名。
- 撤回、遮住答案、音效开关在分组模式下照常可用；`[data-restart]` 逻辑保留但不再出现在分组空态中。
- 不新增 localStorage 键，`wc_mobile_v1` 的 `pos` 在分组期间依旧不写。
