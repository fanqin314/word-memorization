# 词库改版：字母方块 → 分组详情

## 摘要

把当前「中心 → 字母 → 词」的 canvas 思维导图整个替换为你上传的参考稿：

1. **字母方块网格**：每个字母一个方块，方块底色/文字色由该组掌握状态聚合决定（全灰＝未学 / 琥珀＝学习中 / 苔绿＝已掌握），底部 3px 三段进度条显示组内 未学 / 学习中 / 已掌握 占比，方块上写「字母 + N 词」。
2. **点字母 → 飞入详情**：方块字母飞到顶部大徽章，网格淡出缩放，随后 2 列单词卡逐张错峰弹出；点「返回」或下滑关闭时，字母飞回方块。
3. **详情单词卡**：单词、音标、释义、掌握度胶囊、「打卡 n/4」，左侧 4px 竖条取该词词源色；点卡片直接打开 `../cards/xxx.html` 完整词卡页。
4. **搜索**：按单词/释义过滤，方块随结果重排（列数自适应），计数同步更新；有关闭按钮。
5. **「刷这组」**：把刷词队列临时替换为该组词并跳到「刷词」页，不污染原有全局进度存档。

## 改动方案

- 新增：

### 2. 用新实现替换整段思维导图（替换 L1665–L2062）

删除全部 canvas 相关代码（`libG/libRAF/libPos/libOpen/libSearchPrev/libSearchOn/buildLibGraph/libLayout/libStep/applyLibQuery/libDraw/libWake/libSleep/libLoop/bindLibGraph/hitTest/clampScale/cssColor` 及 pointer/wheel/resize 绑定），改为 DOM 实现：

**状态**
```js
let libBuilt = false;
let libFilter = '';
let libGroups = new Map();     // 当前过滤后的 letter -> word[]
let libCurrent = null;         // 已展开的字母
let libAnimating = false;
let libTimer = null;           // 搜索防抖
```

**`renderLib()`**（进入 tab 时调用）
- 首次构建外壳：
  ```html
  <div class="lib-stat"><b id="libStatCount">46</b> 个词 · <b id="libStatLetters">17</b> 个字母</div>
  <div class="lib-top"><div class="search-box">〔放大镜 svg〕
    <input id="libSearch" type="search" placeholder="搜单词或释义…">
    <button class="clear" id="libClear" hidden>×</button></div></div>
  <div class="lib-stage"><div class="lib-grid" id="libGrid"></div><div class="lib-detail" id="libDetail"></div></div>
  ```
- 绑定 `input`：取 `.value`，140ms 防抖后 `if(libCurrent) hardCloseLib(); renderLibGrid(v)`；同步 `libClear.hidden`。
- 绑定清空按钮：清值、隐藏按钮、`hardCloseLib()`、`renderLibGrid('')`、`qEl.focus()`。
- 每次进入：`if(libCurrent) hardCloseLib();` 再 `renderLibGrid(libFilter || 搜索框当前值)`，保证掌握度变化后重排。

**`libGroupsOf(q)`**：遍历 `WORDS`，`q` 非空时按 `word.toLowerCase().includes(q) || gloss.toLowerCase().includes(q)` 过滤；按首字母大写分组，组内 `localeCompare` 排序。

**`groupColorInfo(list)`**：全 `m===2` → `{hex:'#6F8B74',label:'已掌握'}`；`m1+m2===0` → `{hex:'#8F9296',label:'未学'}`；否则 `{hex:'#BB9A5A',label:'学习中'}`。`m` 取 `masteryOf(w.word)`。

**`bestCols(n)`**：`n<=2 → max(n,1)`；`3 → 3`；`4 → 2`；`n<=6 → 3`；`n<=8 → 4`；否则 `5`。

**`renderLibGrid(q)`**
- 更新 `libGroups`、统计数字（`总词数` 与 `字母数`），空结果渲染 `<div class="wempty">没有匹配的词，换个关键词试试</div>`（复用/重建该样式，text-align:center）。
- `grid.style.setProperty('--cols', bestCols(used.length))`。
- 每个方块：`data-letter`、`style="--lc:<hex>"`、字母、`N 词`、三段进度条（按 m0/m1/m2 计数用 `flex:<n>` 撑开，0 的不渲染）。

**`libSorted(list)`**：`m` 升序（未学优先），同档按 `localeCompare`。

**`openLibLetter(L)`**（复刻参考稿动画）
1. `libAnimating` 守卫；`libCurrent = L`；`src = grid.querySelector('[data-letter=L]')`，`src.classList.add('hide')`、`grid.classList.add('fade-out')`。
2. `renderLibDetail(L, list, hex)`，`detail.classList.add('show')`、`detail.style.opacity='0'`，读取 `.badge` 的 `getBoundingClientRect()`。
3. 创建 `.flyer`（文字 L、初始 rect＝方块 rect、字号 `width*0.38`、浅底色），append 到 `document.body`；`requestAnimationFrame` 里 transition 到徽章 rect（`translate + scale(sx,sy)`、底色转 62% 混合、字色白、圆角 16px）。
4. 430ms 后移除 flyer、`badge.style.visibility='visible'`、`detail` 透明度过渡到 1、`.w-card` 依次 `animationDelay = i*26ms` 加 `.in`；380ms 后解禁。

**`renderLibDetail(L, list, hex)`**
```html
<div class="detail-top">
  <button class="back-btn" id="libBack">〈 svg</button>
  <span class="detail-title">C · 6 个词</span>
  <button class="bulk-btn" id="libBulk">刷这组</button>
```

- 单词卡：`<div class="w-card" data-word="w.word" style="--rc:' + rootOf(w).color + '">`，内含 `w-word`（`esc(w.word)`）、`w-ipa`（`esc(w.ipa)`，无音标则整行省略）、`w-gloss`（`esc(w.gloss)`，2 行 clamp）、`w-meta`（`<span class="w-mst m{mastery}">MST_LABEL[m]</span>` + `<span class="w-chk">打卡 n/4</span>`，`n = reviewDone(w.word)`，n 为 0 时留空）。
- 绑定：`#libBack` 与 `.badge` → `closeLibLetter()`；`#libBulk` → `queueLibLetter(L, list)`；`.w-card` 点击 → `location.href = '../' + 该词 file`（按 `dataset.word` 在 `list` 里查表）。

**`closeLibLetter()`**：`libAnimating || !libCurrent` 守卫；取 `list = libGroups.get(L)`（不存在则 `hardCloseLib()`）；`badge` rect → 方块 rect（先移除 `src.hide` 再量）；隐藏 badge、移除 `grid.fade-out`；flyer 从徽章飞回方块（底色由 62% 转 12%、字色回深、圆角 12px）；`detail.style.opacity='0'`；420ms 后 `hardCloseLib()`。

**`hardCloseLib()`**：移除所有 `.flyer`、`detail.classList.remove('show')`、`innerHTML=''`、清 inline opacity/transition、移除 `grid.fade-out` 与所有 `.cell.hide`、`libCurrent=null`、`libAnimating=false`。

**详情层下滑关闭**：`touchstart` 记录 `clientY`（若 `.detail-scroll.scrollTop > 0` 则标记 `blocked`），`touchmove` 中若下移 > 80 且非 blocked → `closeLibLetter()`。均为 passive。

**`queueLibLetter(L, list)`（真做分组刷词）**
- 新增模块级 `let deckScoped = false;`（放在 `queue`/`pos` 声明 L1124 附近）。
- `savePos()`（L1089）开头加 `if(deckScoped) return;` —— 分组刷词不写 `mb.pos`，原有全局进度存档原封不动。
- 实现：
  ```js
  function queueLibLetter(L, list){
    if(!list || !list.length) return;
    deckScoped = true;
    queue = libSorted(list).slice();
    pos = 0;
    undoSnap = null;
    renderDeckShell();
    toast('已切到 ' + L + ' 组 · ' + queue.length + ' 个词');
    switchTab('deck');
  }
  ```
- 恢复全局队列：刷词页 `[data-restart]` 的既有处理（L2337）里追加 `deckScoped = false;`（`buildQueue(true)` 已重建全局队列）。除此之外不改 `advance`/`undo` 逻辑。

## 假设与决定

- 采用**参考稿的字母方块 → 详情**形态，完全移除 canvas 思维导图（用户最新指令「做成这样吧」，且已确认两项交互）。
- 详情里的词卡点击**跳转完整词卡页**（`../cards/*.html`，与现有词库行为一致）。
- 「刷这组」**真做**：临时替换全局队列，进入 `deckScoped` 模式，不写 `mb.pos`；`data-restart` 时退出该模式恢复全局队列。
- 分组底色/进度条只反映**当前筛选结果**（与参考稿一致），因此搜索后打开详情只含命中的词，「刷这组」也只刷命中的词。
- 「刷这组」不新建持久化键，不改动任何既有 localStorage 键。
- 音标为空时省略 `w-ipa` 行，不占位。
