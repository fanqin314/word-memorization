# 刷词卡正面·黄金比例排版 + 动效音效 Spec

## Why
手机刷词卡的正面信息密度尚可，但纵向节奏靠经验值拼凑：图形框是 1:1 正方形，短屏上挤占高度；字号阶梯（1.8–2.5rem / .92 / .82 / .73 / .66）没有统一比例；整卡只在入场时有一次淡入，评分/翻面/达成目标都缺少反馈；朗读是唯一的声音。目标是让正面在任意手机高度下比例稳定、层级清楚，并用少量合成动效与音效强化「翻卡—判断」的节奏感。

## What Changes
- 引入黄金比例尺度 token（`--phi` 与 `.382 / .618 / 1 / 1.618rem` 间距阶梯），仅作用于刷词卡正面。
- 正面排版重排：图形框由 1:1 改为 **1.618:1 黄金矩形**（高度 `clamp(96px, 30vh, 214px)`，宽度随比例），释放纵向空间给字号。
- 字号按黄金阶梯重排：词 `clamp(1.95rem, 9.2vw, 2.618rem)`、释义 `1rem`、场景 `.75rem`、构词 `.618rem`、词性 `.618rem`、音标 `.75rem`。
- 正面内容改为「逐级入场」：词 → 音标/词性/释义 → 图形 → 场景/构词 → 操作按钮，40ms 级联，总时长 ≤ 600ms。
- 图形框加入缓慢呼吸（8s，±4px）与入场缩放；评分按钮点击时扩散压印环；翻面加入轻微过冲；今日目标达成时进度线扫光一次。
- 新增基于 WebAudio 的合成音效模块（无外部音频资源）：认识 / 不认识 / 有点印象 / 跳过 / 翻面 / 字母落格 / 拼写正确 / 拼写错误 / 今日达成。
- 刷词页 `deck-meta` 右侧新增 24px 音效开关，状态持久化到**新键** `wc_sound_v1`（不改动 STORE_KEY/MB_KEY/QUIZ_KEY/MST_KEY/`<word>_review`）。
- 全部动效在 `prefers-reduced-motion: reduce` 下自动降级为瞬变；音效在首次用户手势前不发声。

**BREAKING**：无。

## Impact
- Affected specs: 刷词卡正面视觉、动效与音效（新增能力）；刷词/翻面/评分/拼写交互保持不变。
- Affected code: `mobile/index.html`（CSS：`:root` token、`.face`、`.card-head`、`.card-main`、`.word-row`、`.word`、`.ipa`、`.pos`、`.gloss`、`.art-frame`、`.scene`、`.morph`、`.actions`、`.rate`、`.deck-meta`；JS：`advance/rateWord`、翻面处理、拼写判定、`refreshHeader`）。
- 不改：`words-data.js` 字段；既有 localStorage 键名与结构。

## ADDED Requirements

### Requirement: 正面黄金比例排版
刷词卡正面 SHALL 使用黄金比例尺度：图形框宽高比 1.618:1；卡片内边距、块间距来自 `.382/.618/1/1.618rem` 阶梯；字号按黄金阶梯分布（词 > 释义 > 场景 ≈ 音标 > 构词 ≈ 词性）。

#### Scenario: 390×844 常规手机
- **WHEN** 在 390×844 视口打开刷词页
- **THEN** 正面的标题行、词、音标/词性/释义、图形框、场景、构词、三个评分按钮全部完整可见，无裁切、无横向溢出
- **AND** 图形框渲染为 1.618:1，宽度不超过卡片内容宽度

#### Scenario: 390×640 矮屏
- **WHEN** 视口高度 ≤ 640px
- **THEN** 图形框高度压缩到 `30vh` 且最低 96px，其余区块仍全部可见，评分按钮不超出卡片

### Requirement: 正面分层入场动效
卡片切换时，正面内容 SHALL 按「词 → 元信息 → 图形 → 场景/构词 → 操作」顺序级联淡入并轻微上移，单张总时长不超过 600ms。

#### Scenario: 切换到下一张
- **WHEN** 用户完成一次评分或滑动切卡
- **THEN** 新卡正面各块按 0/40/80/120/160/200ms 依次出现，无闪烁、无布局跳动

#### Scenario: 减少动效偏好
- **WHEN** 系统开启 `prefers-reduced-motion: reduce`
- **THEN** 入场动画、图形呼吸、压印扩散全部关闭，仅保留状态切换的即时变化

### Requirement: 交互反馈动效
评分、翻面、进度变化 SHALL 有明确反馈：评分按钮出现扩散压印环；翻面过渡带轻微过冲；`deckPos` 数字变化时做一次 1.25→1 的缩放；今日达标时进度线扫光一次（每天仅一次）。

#### Scenario: 点击「认识」
- **WHEN** 点击任一评分按钮
- **THEN** 按钮按下位移（已有）+ 该按钮语义色的压印环扩散 320ms，不阻塞评分与切卡

#### Scenario: 今日达成
- **WHEN** 今日刷词数首次达到目标 10 个
- **THEN** 顶栏 3px 进度线出现一次 1.2s 光泽扫过，当天不再重复

### Requirement: 合成音效与开关
系统 SHALL 提供低音量合成音效，并在 `deck-meta` 提供持久化开关；音效在首次用户手势前不得发声。

#### Scenario: 评分音效差异
- **WHEN** 用户分别向右/向左/向下/向上滑动或点击对应按钮
- **THEN** 依次播放「认识：上行双音」「不认识：低频短音」「有点印象：中频单音」「跳过：气声」且互不串音

#### Scenario: 拼写与翻面音效
- **WHEN** 字母块落入格子 / 拼写判定正确 / 判定错误 / 翻面
- **THEN** 分别播放落格 click、正确琶音、错误低鸣、翻纸噪声

#### Scenario: 静音持久化
- **WHEN** 用户点击 `deck-meta` 的喇叭按钮关闭音效后刷新页面
- **THEN** 仍保持静音，评分/翻面/拼写均不发声，且朗读（speechSynthesis）不受影响

## MODIFIED Requirements
### Requirement: 刷词卡正面交互
正面继续保持：点按任意空白处翻面、四向滑动评分、朗读按钮、词卡外链、评分按钮三档；本次仅调整排版尺寸与新增动效/音效，不改变判定阈值、方向语义与持久化结构。
