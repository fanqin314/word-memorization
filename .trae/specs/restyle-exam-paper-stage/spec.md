# 期末选择题「考卷舞台」改造 Spec

## Why

期末四选一现在只是「题干 + 四个按钮 + 一行解析」，功能完整但没有情绪：点选后整屏直接重绘，判分瞬间没有任何可看的动作，答对答错的差别只有几行字的颜色。刷词页有翻面、有评分、有音效、有词卡纸面的质感，期末页相比之下像一个后台表单，用户提不起兴趣主动去刷。

目标：在不改变题库数据、判分规则、存档结构和返回键行为的前提下，把答题过程做成一张**会呼吸的考卷**——进入是「铺开卷子」，作答是「填进空格」，判分是「圈选 + 落笔 + 盖章」，结束是「合卷」。

## What Changes

- **视觉方向**：沿用现有瓷白纸（`--paper-2:#FCFCFB`）+ 墨（`--ink:#20242A`）+ 发丝线（`--rule/--rule-2`）+ 等宽小标签（`--mono`）+ 衬线展示字（`--serif/--display`）+ 2px 方角，只新增一个**印章红**（`#A33A1E`，即现有错误色）用于错判与印章。不引入新字体、不引入外部图片、不加依赖。
- **考卷版式**：答题页从「一列文字」改为有版心的卷面——顶部一条「每题一格」的进度刻度、左侧大号衬线题号、题干段落式排版、四个选项做成可按压的纸片。
- **判分三连击**（本次最核心的记忆点）：
  1. 选中项墨色从左灌入（`inkSweep`，约 160ms）；
  2. 题干里的空格被正确答案「写进去」——字母逐字出现 + 一道下划线自左向右画过（`writeIn`，约 240ms）；
  3. 答对盖一枚 ✓ 印章（`stampIn`：放大落下 + 轻微回弹 + 一次 1° 抖动 + 12ms 震动 + 上扬音效）；答错则所选项红线抖一下（`shakeX`），正确项以虚线框「点亮」并上浮 1px，同时盖一枚 ✗ 小章 + 低沉音效。
- **解析**：改成「页边批注」——细竖线 + 等宽「考点」标签 + 从下方 8px 滑入；记忆条排成一张浅色便签贴在批注底部。
- **结果页**：合卷式收尾——巨号衬线分数做 count-up、正确率用横向刻度尺（一格一题，对墨错红）、满分时盖「全对」大章；错题卡片按「题干 → 正确答案 → 考点 → 搭配」的层级排。
- **入口**：题库首页的题组行按下时纸页位移 2px；「全部混合 / 只刷错题 / MEMORY」保持墨块按钮，仅补按下回弹。
- **动效与可访问性**：全部动效为 CSS keyframes + 一次性的 `animation`（无第三方库）；`prefers-reduced-motion: reduce` 下全部降级为即时状态变化；音效与震动复用 `sfxPlay()/sfxHaptic()`，受现有 `wc_sound_v1` 静音开关控制。
- **不做**：不改 `EXAM_GROUPS/EXAM_TRANS/EXAM_MEMO` 任何一条数据；不改判分、错题归属、`wc_exam_v1` 结构；不改答题态隐藏 tabbar 与手机返回键逻辑；不动刷词/词库/自测/数据四个 tab。

**BREAKING**：无。

## Impact

- Affected specs：`add-exam-mcq-bank`（视觉与交互升级，不改变其行为需求）。
- Affected code：`mobile/css/exam.css`（主体）、`mobile/js/exam.js`（`renderExamRun / examRunStem / examOptsHtml / examPick / renderExamResult / renderExam`）；可能少量触及 `mobile/css/chrome.css`（若需全局 `@keyframes` 兜底，优先留在 `exam.css`）；`mobile/js/app.js` 的期末事件委托**不改**。

## ADDED Requirements

### Requirement: 考卷版式

系统 SHALL 把答题页渲染为一张有版心的考卷：顶部进度刻度（每道题一格，已答对的格为墨点、答错为红点、未答为细线）、左侧大号衬线题号（如 `03`）与等宽小题注（Unit / 第几题 / 第几空）、题干按段落排版、四个选项纵向排列且每项可按压。

#### Scenario: 进入一组
- **WHEN** 从题库首页点进任一组
- **THEN** 卷面以约 220ms 的「铺开」动效出现，刻度条上只有第 1 格是当前态，其余为未答细线

#### Scenario: 选项可读可点
- **WHEN** 用户在 375px 宽的手机上看题
- **THEN** 每个选项整行可点、最小触摸高 44px，字母标 A/B/C/D 与文字不换行错位，长短语可自然折行

#### Scenario: 双空题
- **WHEN** 遇到 Unit 3 第 4、7 题
- **THEN** 左侧题注显示「空 1/2」「空 2/2」，两个空各自独立判分，刻度条按空计数

### Requirement: 判分动效（三连击）

系统 SHALL 在用户点选后依次播放三段动效，且**同一题只判一次**：点选后先给被点选项加按压/墨染态，约 140ms 后再按已落盘的状态重绘这一屏，重绘出的空格与印章各自播放一次入场动画。

#### Scenario: 答对
- **WHEN** 点中正确选项
- **THEN** 该选项墨色从左灌入并转成墨底白字；题干空格里正确答案逐字出现、下划线自左向右画过；右上角落下 ✓ 印章；播放一次上扬音效并短震动；其余选项降到 45% 存在感

#### Scenario: 答错
- **WHEN** 点中错误选项
- **THEN** 被选项红线抖一下并标红；正确选项以虚线框点亮并上浮 1px；题干空格填入正确答案（红色）；右上角落下 ✗ 小章；播放低沉音效

#### Scenario: 连点与重复点击
- **WHEN** 判分动画还没结束就再点其他选项或同一选项
- **THEN** 不重复判分、不重复累计正确数、不重复写入错题，界面最终只呈现第一次选择的结果

#### Scenario: 减弱动效
- **WHEN** 系统开启「减弱动态效果」
- **THEN** 不播放位移/缩放/逐字动画，判分结果以即时换色呈现，音效仍遵守静音开关

### Requirement: 解析批注与记忆便签

系统 SHALL 在判分后把解析改成页边批注样式：左侧 2px 竖线、等宽「考点」小标签、正文 0.74rem/1.6 行高；下方若有记忆条，则以浅纸色便签呈现（词形 / 提示搭配 / 中文，变形部分加粗）。

#### Scenario: 判分后出现
- **WHEN** 任一题判分完成
- **THEN** 批注自上而下 8px 滑入，约占 200ms，不推动选项跳动；记忆便签紧随其后出现

### Requirement: 合卷结果页

系统 SHALL 把结果页做成「合卷」：巨号衬线分数（如 `9 / 10`）用 500ms count-up 从 0 涨到实际值、正确率刻度尺一格一题（对墨错红）、满分时盖「全对」大章；错题以卡片列出题干（空格内嵌正确答案）、正确选项、考点与搭配记忆。

#### Scenario: 有错题
- **WHEN** 一组答完且答错若干
- **THEN** 分数与刻度尺正确反映对错；“重做错题 / 再来一轮 / 返回题库”三键可用，“重做错题”在无错题时禁用

#### Scenario: 全对
- **WHEN** 一组全部答对
- **THEN** 结果页出现「全对」印章与「这组可以放下了」，刻度尺整条为墨

### Requirement: 入口与按压反馈

系统 SHALL 在题库首页给题组行与入口按钮补轻量按压反馈（行最多位移 2px、按钮按下缩放 0.985），不新增装饰性图形。

#### Scenario: 点组
- **WHEN** 手指按住某题组行
- **THEN** 该行轻微下沉并出现纸页阴影，松手后进入答题

## MODIFIED Requirements

### Requirement: 答题态收导航与返回键（沿用）

进入答题 / 汉译英 / 记忆库 / 结果页时仍隐藏底部导航，手机返回键与「← 题库」仍回到题库首页；本次改造只在卷面内部增加动效，不改变历史记录与导航的进出时机。

## REMOVED Requirements

无。
