# Checklist

- [ ] 新卡落入 `d:\apt\英语单词` 后 5 秒内自动改名并生成 `words-data.js`
- [ ] 新卡落在 `%USERPROFILE%\Downloads` 后能被自动搬入并处理
- [ ] 同步进程为单实例：重复启动不会产生第二个监听进程
- [ ] 监听进程与手动 `更新单词数据.bat` 不会并发执行 git
- [ ] 推送失败会按 30/60/120/300 秒退避重试，并在恢复后完成推送
- [ ] `.sync.log` 记录检测/改名/生成/推送时间戳与结果，且长度不超过 500 行
- [ ] `开启自动同步.bat` 双击后监听立即生效且登录后自动启动
- [ ] `停止自动同步.bat` 双击后监听退出、自启关闭
- [ ] 计划任务每 30 分钟检查一次，进程缺失时自动拉起
- [ ] `.gitignore` 已忽略 `.sync.pid` / `.sync.log` / `.sync-state`
- [ ] 本机以 `file://` 打开 `index.html` 时新词立即出现在列表与搜索中
- [ ] 手机上 GitHub Pages 在推送后约 1 分钟内可看到新词
