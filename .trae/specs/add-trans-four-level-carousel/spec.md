# 汉译英四档记忆与轮播输入 Spec

## Why

当前汉译英只有一档写法（中文 + 词块 + 参考），写不出来时只能整句看参考；反馈也集中在整段结算，单句内部只有词块亮起。参考稿把「记忆难度」拆成四档：先排序认句，再全提示跟写，再只给首字母，最后纯回忆；输入时把当前词放大、逐字母判对，单句写完立刻给覆盖率。这能把"一次写完一段"的长任务切成一口一口的小任务，正反馈密度也更高。

## What Changes

- 每句增加「记忆等级」四档：排序 / 全提示 / 首字母 / 回忆，默认全提示；切档保留已写内容，但撤销该句的判分。
- 排序档（L1）：整句英文打乱成词块，点选按顺序排列；词块位置固定不挪动；5 秒无操作高亮下一个正确词块；点错标红、可撤回；检查给顺序正确率。
- 全提示档（L2）：保留现有完整词块，新增逐词进度条（`x / y 词`）与「下一个词：x…」首字母提示；输入区改为轮播词模式。
- 首字母档（L3）：词块只显示每个词前 3 个字母 + 省略号。
- 回忆档（L4）：隐藏词块、进度与首字母提示，只留中文、输入区和「看这句参考」。
- 轮播输入（L2–L4）：聚焦时当前词放大、已完成词缩小；逐字母判对，错字母标红并抖动；拼对当前词自动补空格；超宽自动滚动到当前词；失焦回到普通文本外观。
- 词块点亮改为按参考句中的位置区间判定：输入前缀覆盖到词块末尾才点亮；保留每词块一次轻响、全部点亮时中文左侧变绿。
- 单句内联检查：点「检查」后在本句显示覆盖率、你的 / 参考、漏词；输入锁定，可「重写这句」；按钮变成「下一句」。
- 已完成句子从单行纸条改为可展开记录（`01 已完成 ▸`，展开显示你的与参考）。
- 最后一句检查后进入整段回放页：整段覆盖率、逐句「中文 / 你的 / 参考」错落淡入、再来一遍 / 返回题库；保留本单元最好成绩与「独立完成 / 看了参考」统计。
- 等级偏好写入现有 `wc_exam_v1`（新增 `transLv` 字段），不改动任何既有 localStorage 键。

**BREAKING**：逐句流程由「写完直接下一句」改为「检查 → 下一句」，不再保留旧的一步跳转。

## Impact

- Affected specs：`add-trans-sentence-scaffold`（逐句支架被扩展为四档）、`add-exam-mcq-bank`（题库入口与存储结构保持兼容）
- Affected code：
  - `mobile/js/exam.js`：`examTransRun` 状态、`examStartTrans` / `examTransInput` / `examTransStepNext` / `examTransStepPrev` / `examTransToggleRef` / `examTransReveal` / `renderExamTrans` / `renderExamTransResult`、`#view-exam` 事件委托
  - `mobile/css/exam.css`：`.ex-tr-*` 重写与新增（等级条、排序区、轮播区、进度、反馈、回放）
  - `mobile/index.html`：不改脚本顺序与容器
- 不改：题库 / 记忆库 / 四选一 / 刷词 的全部行为；`sfxPlay` 音效名；`history` 返回逻辑。

## 设计方向（frontend-design）

把逐句页当成一张**校样纸**：四档等级是逐步撤走的脚手架，轮播输入是打字机的当前字位。

- 保留现有纸面语言：瓷白 `--paper-2`、墨 `--ink`、发丝线、等宽 + 衬线、2px 方角；不引入参考稿的圆角卡片与深色模式。
- 层级只有三层：当前词（衬线、大、墨）> 中文句（衬线 1.06rem）> 词块与标签（等宽、小、褪色）。
- 动效只保留三处高价值时刻：词块点亮（一次轻弹）、当前词放大位移、回放列表错落淡入；全部尊重 `prefers-reduced-motion`。
- 颜色只表达状态：钢蓝 = 参考/提示，绿 = 命中，批注红 = 错字母/漏词。

## ADDED Requirements

### Requirement: 四档记忆等级

系统 SHALL 在每句写译区提供「排序 / 全提示 / 首字母 / 回忆」四档切换，并在同一单元内保持所选等级。

#### Scenario: 切换等级

- **WHEN** 用户点「首字母」
- **THEN** 当前句词块变为每个词前 3 个字母 + 省略号，已写内容与光标保留
- **AND** 若该句已判分，撤销判分回到可编辑态

#### Scenario: 等级记忆

- **WHEN** 用户退出后重新进入任一单元的汉译英
- **THEN** 默认沿用上次选择的等级（存于 `wc_exam_v1.transLv`）

### Requirement: 排序档

系统 SHALL 在 L1 用打乱词块代替文字输入，并按位置给出即时对错。

#### Scenario: 点选与撤回

- **WHEN** 用户点池中的词块
- **THEN** 该词进入答案区；位置正确为绿、错误为红；池中该词只隐身、不挪位
- **AND** 点答案区任意词块可撤回该词及之后的词

#### Scenario: 5 秒提示

- **WHEN** 排序档 5 秒无操作且尚未选完
- **THEN** 下一个正确词块高亮脉冲

#### Scenario: 排序检查

- **WHEN** 用户点「检查」
- **THEN** 显示正确位置占比与参考句；全对提示可进入下一句

### Requirement: 轮播输入与逐字母反馈

系统 SHALL 在 L2–L4 聚焦时把输入按词渲染成轮播，并对当前词逐字母判对。

#### Scenario: 当前词强调

- **WHEN** 输入框获得焦点且有输入
- **THEN** 当前词放大显示、已完成词缩小褪色；当前词超宽时自动横向滚动到距左侧约 34px

#### Scenario: 错字母

- **WHEN** 当前词某字母与参考不一致
- **THEN** 该字母标红并抖动，但不阻断继续输入

#### Scenario: 自动空格

- **WHEN** 光标在末尾且刚写完的词与参考对应位置匹配
- **THEN** 自动补一个空格，光标停在空格后

#### Scenario: 失焦

- **WHEN** 输入框失焦
- **THEN** 回到普通文本外观，内容不清空

### Requirement: 逐词进度与首字母提示（L2）

系统 SHALL 在 L2 显示逐词进度与下一个词首字母提示。

#### Scenario: 进度更新

- **WHEN** 用户继续输入
- **THEN** 进度条与 `x / y 词` 实时更新（按参考句前缀逐词匹配，前 5 字母相同即算命中）

#### Scenario: 下一个词

- **WHEN** 句子尚未写完
- **THEN** 显示「下一个词：首字母 + …」；写完后显示「整句已写完，点检查」

### Requirement: 词块按位置点亮

系统 SHALL 在 L2/L3 按参考句位置区间判定词块是否点亮。

#### Scenario: 点亮

- **WHEN** 输入的前缀词序列已覆盖到某词块在参考句中的末尾
- **THEN** 该词块变为实线 + 绿 ✓，并只播放一次轻响
- **AND** 当前句全部词块点亮时，中文句左侧竖线变绿

#### Scenario: 回删

- **WHEN** 用户删掉已覆盖的内容
- **THEN** 对应词块熄灭，中文句恢复未完成态

### Requirement: 单句内联检查

系统 SHALL 在检查后把本句结果内联展示，而不是直接跳句。

#### Scenario: 检查通过

- **WHEN** 用户点「检查」且本句覆盖率 ≥ 60%
- **THEN** 显示绿色大号覆盖率、「你的 / 参考」两行与漏词；按钮变为「下一句 →」

#### Scenario: 检查未通过

- **WHEN** 覆盖率 < 60%
- **THEN** 覆盖率用批注红显示，并保留参考与漏词供对照；不阻止进入下一句

#### Scenario: 重写

- **WHEN** 已检查的句子点「重写这句」
- **THEN** 撤销本句判分、恢复可编辑，已写内容保留

### Requirement: 整段回放

系统 SHALL 在最后一句检查后进入整段回放。

#### Scenario: 回放内容

- **WHEN** 进入回放
- **THEN** 显示整段覆盖率（沿用 `trCoverage(t.en, 全文)`）、逐句「编号 · 覆盖率 / 中文 / 你的 / 参考」，并按 260ms 起的间隔错落淡入

#### Scenario: 结算与再来一遍

- **WHEN** 进入回放
- **THEN** 只在此刻更新 `examData.trans` 的 `seen / right / best / last`
- **AND** 提供「再来一遍」（清空逐句内容与判分，等级保留）与「返回题库」

## MODIFIED Requirements

### Requirement: 逐句推进与进度

保留顶部刻度、`SENTENCE 0X / 0Y`、中文主体、「看这句参考」、「上一句」；底部主按钮改为「检查 → 下一句 → 看整段回放」。

## REMOVED Requirements

### Requirement: 句子完成即跳下一句

**Reason**：没有单句反馈，正反馈只在整段结算出现一次。

**Migration**：由「检查」内联反馈替代，最后一句改为整段回放页。

## 约束与兼容

- 不改任何既有 localStorage 键；仅在 `wc_exam_v1` 增加 `transLv`。
- 逐句草稿只在本次进入期间保存在内存，刷新后重新开始（不写盘）。
- 375px 宽不出现横向滚动；所有可点区域 ≥ 44px。
- 输入过程只增量更新当前词、进度与词块，不整体重绘，避免打字卡顿。
