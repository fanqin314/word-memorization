# 词库详情层杂志化改造 Spec

## Why
词库字母墙已经改成「米色新闻纸 + 17 种字体样本」的标本册风格，但点开字母后的详情层 `.lib-detail` 仍是旧的瓷白卡片界面（彩色方块徽章 + 白底词卡 + 蓝灰强调线），两屏风格完全割裂。参考稿的十种词卡变体虽是同一套语言，但逐个搬过来既不完整，也会让信息读起来散乱。本改动把详情层改成同一本标本册里的「内页」：沿用墨色 + 米纸 + 发丝线的版式，同时保留本项目真正需要的东西（掌握度、打卡次数、刷这组、点词跳转）。

## What Changes
- `.lib-detail` 从绝对定位的空白浮层改为米纸内页：米色纸底 + 与字母墙一致的纸纹，内边距与墙面留白对齐；顶部条改为发丝线下压的编辑版式。
- 徽章从「彩色圆角方块」改为「墨色标本牌」：84px、2px 方角、四角细线标记、米色单字；17 种字形与本字母在墙面上的字体一一对应（`.lib-detail[data-style="a"…"w"]`）。
- 徽章右侧新增「标本标签栏」（`badge-meta`）：字母 / 字体名 / 掌握进度三行 + 一条 2px 掌握度细进度线（沿用 #8F9296 / #BB9A5A / #6F8B74 语义色，但不抢墨色主调）。
- 词卡改为单一系统化的「编辑版式」而不是十种随机变体：2 列网格，首张在词数 ≥3 时跨两列做导语卡（衬线大字 + 青铜色首字），其余卡统一为「序号 + 衬线词 + 等宽音标 + 青铜/词卡色引线释义 + 发丝线 + 掌握度点标签 + 打卡」。
- 词卡入场保留交错，但改用 `backwards` 填充，避免动画终帧覆盖后续 transform。
- 飞行动画落点改为按徽章实际计算样式取值（背景 / 文字色 / 字号），从墙面裸墨字起飞、落到徽章才「染上」墨底米字。
- 抽出 `libFaceKey(L)` 统一墙面与详情的字体映射，避免两处各写一遍。
- 非**BREAKING**：localStorage 键、词库数据结构、队列行为、点词跳转路径均不变。

## Impact
- Affected specs：`magazine-letter-wall`（既有字母墙，仅复用其字体语言，不改动其行为）
- Affected code：`mobile/index.html`
  - CSS：`.lib-detail` / `.detail-top` / `.back-btn` / `.detail-title` / `.bulk-btn` / `.badge` / `.detail-scroll` / `.w-grid` / `.w-card` 及其子元素（约 1210–1281 行）
  - JS：`renderLibDetail`（约 2595–2630 行）、`renderLibGrid` 内的 `data-style` 推导（约 2574–2593 行）、`libFly`（约 2653–2700 行）、`openLibLetter` 的入场延迟（约 2718–2760 行）

## ADDED Requirements

### Requirement: 详情层作为「内页」
详情层 SHALL 与字母墙使用同一张米色新闻纸：同底色、同纸纹、同左右留白，打开时不再露出底层网格。

#### Scenario: 打开任意字母
- **WHEN** 用户点击字母墙上的任一 `.spec`
- **THEN** 详情层铺满 `.lib-stage`，背景为 `var(--news)` + 同一层纸纹，顶部条与卡片不贴边
- **AND** 返回后字母墙滚动位置与之前一致

### Requirement: 墨色标本牌与 17 种字形
详情层 SHALL 用墨底米字的方角徽章展示当前字母，并让徽章字形与该字母在墙面上的字体一致。

#### Scenario: 字形一一对应
- **WHEN** 打开字母 `C`（墙面为 Impact Condensed）
- **THEN** 详情徽章为横向压缩的 Impact 字形
- **AND** 打开 `D`（Outline 2pt）时徽章为米底 + 描边墨字，`S`（Inverse Block）为米底 + 反白墨块

### Requirement: 标本标签栏展示项目真实信息
徽章旁 SHALL 展示字母、字体名、掌握进度，并保留掌握度颜色语义。

#### Scenario: 掌握度可见
- **WHEN** 该组 6 个词中 2 个已掌握、1 个学习中
- **THEN** 标签栏显示 `STUDIED 2 / 6`，细进度线按 2/6 填充且使用本组当前主导掌握色（未学灰 / 学习金 / 掌握绿）

### Requirement: 统一的编辑版式词卡
词卡网格 SHALL 使用同一套版式，而不是随机切换十种互不相干的变体。

#### Scenario: 首张跨列导语卡
- **WHEN** 该组词数 ≥ 3
- **THEN** 第一张卡横跨两列，用衬线大字 + 青铜色首字 + 序号
- **AND** 其余卡两列排布，含序号、衬线词、等宽音标、引线释义、掌握度点标签与打卡次数

#### Scenario: 点词跳转
- **WHEN** 用户点击任一词卡
- **THEN** 仍跳转到 `'../' + w.file`，与现行为一致

### Requirement: 飞行动画与新徽章对齐
字母从墙面飞入详情时 SHALL 以裸墨字起飞，落到墨色标本牌上，落点的底色/字色/字号取自徽章的实际计算样式。

#### Scenario: 落点匹配
- **WHEN** 打开字母 `D`（徽章为米底描边字）
- **THEN** 飞行体落地时底色为米纸、文字使用可读的墨色（描边/透明字回退为墨色），字号与徽章字一致，不出现彩色残影

## MODIFIED Requirements

### Requirement: 详情层顶部条与动作
顶部条 SHALL 采用发丝线下的编辑版式：方角返回按钮（墨线描边、按下反白）、居中等宽标题、方角「刷这组」墨按钮。

#### Scenario: 返回与刷词
- **WHEN** 用户点击返回或徽章
- **THEN** 详情层按现有 `closeLibLetter` 流程关闭
- **AND** 点击「刷这组」仍调用 `queueLibLetter(L, libGroups.get(L))` 进入队列

### Requirement: 动效与事件
所有新增动效 SHALL 只动画 `transform` / `opacity`，并遵守 `prefers-reduced-motion`；事件处理 SHALL 阻止默认与冒泡，不新增重复绑定。

#### Scenario: 事件只触发一次
- **WHEN** 快速连点返回或词卡
- **THEN** 每次点击只执行一次对应动作，无重复绑定、无事件穿透到墙面
